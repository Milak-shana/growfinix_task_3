# 🎨 Student Task Management App – Visual UI Design & Design System

## 📌 Internship Task

This project was created as part of my **UI/UX Design Internship at Growfinix Technology**.

The objective of Task 3 was to convert the low-fidelity wireframes created in the previous task into polished, visually appealing, and user-friendly high-fidelity UI designs.

## 🎯 Project Goal

The goal was to create a consistent visual experience for a **Student Task Management App** while maintaining clear navigation and usability.

The design focuses on helping students manage:

- 📚 Academic tasks
- 📅 Deadlines
- 🎯 Task priorities
- 🔔 Reminders
- 📊 Progress and task completion

## 🎨 Visual Design

A modern and student-friendly visual style was created with a focus on:

- Consistent colors
- Clear typography
- Comfortable spacing
- Rounded UI elements
- Clean cards and layouts
- Clear visual hierarchy
- Easy-to-use navigation

## 🧩 Design System

A reusable design system was created to maintain consistency across all application screens.

The design system includes:

- 🎨 Color palette
- 🔤 Typography hierarchy
- 📏 Spacing and layout guidelines
- 🔘 Buttons
- 📝 Input fields
- 🃏 Task cards
- 🏷️ Priority labels
- 📊 Progress indicators
- 🧭 Bottom navigation

## 📱 Application Screens

### 🏠 Dashboard

The dashboard provides an overview of upcoming tasks, deadlines, priorities, and overall task progress.

### ➕ Add New Task

This screen allows students to create tasks by entering details such as the task title, subject, deadline, priority, description, and reminder settings.

### 📄 Task Details

Users can view complete information about a selected task, including its deadline, priority, reminder, and current status.

### ✏️ Edit Task

This screen allows users to update or modify existing task information.

### ✅ Task Completed

A clear success state confirms when a student successfully completes a task.

### 📊 Progress Overview

The progress screen helps users monitor completed tasks, pending tasks, and their overall productivity.

## 🤖 AI-Assisted Design

ChatGPT/Gemini AI was used during the design process to:

- Explore visual design ideas
- Suggest accessible color combinations
- Improve UX writing
- Generate design ideas
- Review visual consistency
- Improve usability

## 🛠️ Tools Used

- Figma
- Canva
- ChatGPT/Gemini AI

## 🚀 Key Learning

This task helped me understand how low-fidelity wireframes can be transformed into polished high-fidelity interfaces.

I also learned the importance of maintaining a consistent design system, using reusable components, creating a clear visual hierarchy, and making design decisions that improve the overall user experience.
